# Contributing to Smart House Research Toolkit

The project is intended to make environmental and IoT data from the DigiTech Smart House Data Pack easier to analyse using reusable Python tools.

Contributions are welcome from developers, students and anyone interested.

## Project principles

When contributing, please keep these in mind:

- Do not assume that every dataset year has the same files, sensors or schema.
- Preserve the distinction between dataset release year and actual observation dates.
- Add tests for new behaviour.
- Avoid silently guessing when data is malformed or unsupported.
- Keep the original dataset out of the repository.
